# Android-iconen (voor later)

Launcher-iconen van Verenigd voor een eventuele app of PWA bij fase 7 (webapp groepsleiders, besluiten 33–37). Versie 3 (2026-10-29): opnieuw gemaakt uit het aangeleverde ontwerp (`assets/bron/verenigd-icoon-1024.png`), met echte transparantie rond de afgeronde tegel.

| Map | Formaat |
|---|---|
| `mipmap-mdpi` | 48 × 48 |
| `mipmap-hdpi` | 72 × 72 |
| `mipmap-xhdpi` | 96 × 96 |
| `mipmap-xxhdpi` | 144 × 144 |
| `mipmap-xxxhdpi` | 192 × 192 |
| `playstore-icon` | 512 × 512 |

- Er is (nog) geen *adaptive icon* (aparte voor- en achtergrondlaag); voor Android 8+ is die later aan te maken.
- Voor een webapp/PWA zijn vooral 192 en 512 px nodig; die staan hier al.
- Deze bestanden worden niet meegebouwd met de desktop-app. Het Windows-icoon staat in `src/Verenigd.App/Assets/Verenigd.ico`.
